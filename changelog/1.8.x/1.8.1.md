# 1.8.1 — 2026-10-29

## Changed

- **`arxiv_read_paper` HTML bodies** drop LaTeXML presentation markup — `style` attributes, link `title`s, `visibility:hidden` (`\phantom`) spans with their content, and attribute-less `<span>` wrappers — and render span-built tabulars as `<table>` markup. `body_characters`, `start`, and outline offsets move with the shorter body (#94).
- **README's local-mirror section** moved to `docs/mirror.md`, now shipped in the npm package, with a v5 → v6 migration-cost row and a list of how mirror answers differ from the live API.
- **`arxiv-guide` skill** 1.0 → 1.1: the quoted-author-name gate states arXiv's within-one-author, any-order matching (#96).

## Fixed

- **Mirror metadata matches the live API's** (#89): harvested TeX becomes Unicode (a port of arXiv's `tex2utf`), author lists split as arXiv's `split_authors` does, and `published`/`updated` drop the `.000`. Mirror schema v6; a writer migrates existing files in place on its next open, so `au:Barragan` finds the papers stored as `Barrag\'an`.
- **`content[]` keeps TeX byte-for-byte** in `arxiv_search_papers`, `arxiv_get_metadata`, and `arxiv_read_paper` (#91): titles, author lines, abstracts, comments, and `arxiv_read_paper` headings and outline titles sit in code spans or `text` fences instead of escaped inline text, and `instructions` say so. Live author names holding a whitespace run now collapse to one space in `structuredContent`.
- **`arxiv_get_metadata` looks up each distinct ID once** (#92): a bare ID, its `arXiv:` form, and its abs URL are one lookup and one of the 10 slots; `1706.03762` and `1706.03762v7` stay separate. `papers`, `not_found`, `remaining_ids`, and `Found N of M` count distinct IDs.
- **`no_match` no longer tells callers to check the ID format** on `arxiv_read_paper`, `arxiv_get_metadata`, and `arxiv://paper/{paperId}` (#93): the message reads `arXiv has no paper with ID '…'.` (`paper or version` when the ID pins `vN`) and the recovery points to `arxiv_search_papers`. Reason codes and `data` are unchanged.
- **Multi-word `au:` queries go to the live API** (#96) — a quoted name, `au:J.A.Hinton`, or `au:del_maestro`. arXiv matches them inside one author's name in any order; the mirror matched an ordered phrase across the whole author list. The `query` description now suggests a surname plus a category or topic.
- **Paper IDs with an impossible month fail `invalid_id`** (#98): `2400.00001` and `hep-th/9913001` (`YYMM` month `00` or `13`–`99`) no longer reach arXiv or the mirror, where 1.8.0 reported them absent.
