# 1.8.2 — 2026-11-08

## Added

- **`arxiv_get_metadata` accepts `paper_id`, `arxiv_id`, `id`, and `ids`** as aliases of `paper_ids` (#102). An alias beside `paper_ids` is rejected; the advertised `inputSchema` is unchanged.
- **`arxiv_search_papers` `sort_by` accepts arXiv's `submittedDate` and `lastUpdatedDate`** as `submitted` and `updated`, in any case and with surrounding whitespace (#105). Live and mirror searches receive the canonical value; the advertised enum is unchanged.

## Changed

- **`invalid_id` recovery on `arxiv_get_metadata`, `arxiv_read_paper`, and `arxiv://paper/{paperId}`** ends by pointing a title, author, or topic at `arxiv_search_papers`, as does the `not_found` detail for a malformed ID in `arxiv_get_metadata` (#104). Messages and reason codes are unchanged.
- **`arxiv-guide` skill** 1.1 → 1.2: the identifier table passes `arXiv preprint arXiv:…` as `arXiv:…`; the author-name gate covers ASCII spellings (#100), the cross-list gate canonical codes (#99), the pinned-version gate a pin the mirror holds (#103), and the version-suffix note pinned IDs and a mirror's last refresh.
- **Framework sync** to mcp-ts-core 0.13.22: `framework-skills/`, `scripts/`, `changelog/template.md`, and `.env.example` (`MCP_JWT_EXPECTED_AUDIENCE`, `MCP_JWT_EXPECTED_ISSUER`).

## Fixed

- **Mirror metadata lists alias and subsumed category codes as the API does** (#99): `primary_category` and `categories` hold canonical codes (`cs.NA` → `math.NA`, `chao-dyn` → `nlin.CD`). An alias in `cat:` or `category` means its canonical code on both paths, and an archive or wildcard spanning an alias adds its canonical code (`cs` also matches `math.NA` and `eess.SY`). No stored row changes.
- **Author names with `ł`, `ı`, `ø`, `đ`, `ð`, `þ`, `ħ`, `ŋ`, `ə`, `æ`, `œ`, or `ß` match their ASCII spelling on the mirror**, as arXiv's author search does (#100): `au:Tworzydło` and `au:Tworzydlo` find the same papers. Mirror schema v7: the first writer open rebuilds the full-text index once, with no paper row changes, and `mirror:verify` also checks the index, its content view, and its sync triggers. Rolling back to 1.8.1 serves the v7 file but searches such a name as written; `docs/mirror.md` has the cost and rollback notes.
- **A version-pinned `arxiv_read_paper` takes its metadata from the mirror when it holds that version** (#103), with no live lookup, so the read no longer waits in the arXiv API queue.
