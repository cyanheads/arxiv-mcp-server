# 1.8.2 — 2026-11-08

## Added

- **`arxiv_get_metadata` accepts `paper_id`, `arxiv_id`, `id`, and `ids`** as aliases of `paper_ids` (#102). An alias beside `paper_ids` is rejected; the advertised `inputSchema` is unchanged.
- **`arxiv_search_papers` `sort_by` accepts arXiv's `submittedDate` and `lastUpdatedDate`** as `submitted` and `updated`, in any case and with surrounding whitespace (#105). Live and mirror searches receive the canonical value; the advertised enum is unchanged.

## Changed

- **`invalid_id` recovery on `arxiv_get_metadata`, `arxiv_read_paper`, and `arxiv://paper/{paperId}`** ends by pointing a title, author, or topic at `arxiv_search_papers`, as does the `not_found` detail for a malformed ID in `arxiv_get_metadata` (#104). Messages and reason codes are unchanged.
- **`arxiv-guide` skill** 1.1 → 1.2: the identifier table passes `arXiv preprint arXiv:…` as `arXiv:…`, since the tools reject the longer form.
- **`arxiv-guide` skill** 1.1 → 1.2: the note on a returned `id`'s version suffix now covers pinned IDs and a mirror's last refresh.
- **Dependencies:** `@cyanheads/mcp-ts-core` ^0.13.18 → ^0.13.22, `fast-xml-parser` ^5.11.2 → ^5.12.0, `unpdf` ^1.9.1 → ^2.1.0, `@biomejs/biome` ^2.6.3 → ^2.6.6, `@types/node` ^26.6.5 → ^26.6.6, `tsc-alias` ^1.9.9 → ^1.9.10, `vitest` ^5.0.5 → ^5.1.0; `engines.bun` >=1.4.0 → >=1.4.4.
- **Framework sync** to mcp-ts-core 0.13.22: `framework-skills/`, `scripts/`, `changelog/template.md`, and `.env.example` (`MCP_JWT_EXPECTED_AUDIENCE`, `MCP_JWT_EXPECTED_ISSUER`).

## Fixed

- **Mirror metadata and category filters read alias and subsumed codes as the API does** (#99): `primary_category` and `categories` hold canonical codes (`cs.NA` → `math.NA`, `chao-dyn` → `nlin.CD`), and an alias in `cat:` or `category` means its canonical code on both paths. No stored row changes.
- **Author names with `ł`, `ı`, `ø`, `đ`, `ð`, `þ`, `ħ`, `ŋ`, `ə`, `æ`, `œ`, or `ß` match their ASCII spelling on the mirror**, as arXiv's author search does (#100): `au:Tworzydło` and `au:Tworzydlo` find the same papers. Mirror schema v7: the first writer open rebuilds the full-text index once, with no paper row changes. Rolling back to 1.8.1 serves the v7 file but searches such a name as written; `docs/mirror.md` has the cost and rollback notes.
- **A version-pinned `arxiv_read_paper` takes its metadata from the mirror when it holds that version** (#103), with no live lookup, so the read no longer waits in the arXiv API queue. `version_unavailable` now applies only to a pin the mirror does not hold.
