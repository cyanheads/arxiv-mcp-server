# 1.5.4 — 2026-10-04

## Changed

- **Tool error text now closes with `(reason <reason> · request <id>)`, and `structuredContent.error.data` carries `requestId`** — the id the server's own log records for that call carry (mcp-ts-core 0.13.10). In 1.5.3 the line read `(reason <reason>)` and `data` had no `requestId`.
- **Declared recovery hints reach callers without per-throw forwarding.** The `ctx.recoveryFor()` spreads in the arXiv service, `arxiv_get_metadata`, and the `arxiv://paper/{paperId}` resource are removed; the framework fills `data.recovery.hint` from each definition's `errors[]` (mcp-ts-core 0.13.10). The hint text callers receive is unchanged.
- **An integer sent for a string parameter is converted to its digits instead of rejected** — `arxiv_search` with `query: 42` now searches for `"42"`, where 1.5.3 returned an `invalid_arguments` error (mcp-ts-core 0.13.9).
- **Docker image installs production dependencies in a `deps` stage on the build platform** and cross-installs for the target architecture, so multi-arch builds no longer run Bun under emulation, with the OpenTelemetry peers installed by the new `scripts/install-otel.ts` (mcp-ts-core 0.13.10). Musl-only native packages are pruned from the glibc image by the new `scripts/prune-musl-packages.ts` (mcp-ts-core 0.13.11). Base images move to `oven/bun:1.4.2`, and the Dockerfile no longer sets `MCP_FORCE_CONSOLE_LOGGING`.
- **`server.json` npm entries** drop the `run start:stdio` / `run start:http` package arguments and set `runtimeHint: "npx"`; the `streamable-http` entry fixes `MCP_TRANSPORT_TYPE` to `http` as a value, so a registry client launching the HTTP entry gets the HTTP transport (mcp-ts-core 0.13.11).
- **`.gitignore` and `.dockerignore` ignore every `.env*` file** (`.gitignore` keeps `.env.example`, `.env.template`, `.env.sample`); `.dockerignore` also excludes the `.mcpregistry_*` token files.
- **`.env.example` gains the framework's current variable block** — `MCP_HTTP_MAX_BODY_BYTES`, `MCP_PUBLIC_URL`, `MCP_REQUEST_STATE_KEY`, `MCP_HTTP_RESUMABILITY*`, `MCP_GC_PRESSURE_INTERVAL_MS`, `MCP_LOG_RATE_LIMIT_*`, `LOG_TOOL_FAILURE_PAYLOAD*`, and the per-signal `OTEL_EXPORTER_OTLP_*_ENDPOINT` overrides, all commented out.
- **`package.json`**: `files` excludes `dist/*.mcpb`; `packageManager` moves to `bun@1.4.2`. README badges move to MCP SDK `^2.2.0` and Bun `v1.4.2+`.
- **`.mcpbignore`** excludes `/docs/idea.md` and `/logs/`.
- **`.github/workflows/codeql.yml`** runs one job per language (`actions`, `javascript-typescript`), each uploading under `/language:<language>`.
- **`devcheck.config.json`** gains an empty `outdated.allowlist`.
- **Repo tooling re-synced from mcp-ts-core** — `framework-skills/`, the `devcheck`, `lint-mcp`, `lint-packaging`, `release-github`, and `check-skill-versions` scripts, and the `CLAUDE.md` / `AGENTS.md` agent protocol.
- **Tests** updated for the framework behavior: the argument-rejection test sends a boolean instead of an integer, and a new test asserts the `arxiv_search` contract hint reaches `data.recovery.hint` at the tool boundary.
