# 1.5.1 — 2026-08-22

## Added

- **`arxiv://categories`** advertises a public 24-hour cache hint to clients using protocol revision 2026-07-28.

## Changed

- **HTTP transport** supports protocol revision 2026-07-28 while existing 2025 sessions remain supported.
- **Tool inputs** reject unknown top-level arguments instead of silently stripping them; send only schema-declared keys.
- **Advertised tool output schemas** include the error envelope, allowing clients to validate error results.
- **Mirror refresh logging** uses the SDK v2 closed request context and `withExtra()` metadata.
- **Runtime image** uses Bun 1.4.0, builds on the target platform, and omits optional peers from production installs.
- **MCPB bundling** uses npm's package runner because Bun 1.4.0 cannot resolve the bundle tool's transitive dependencies.
- **Community health files** add contributing and conduct guidance, and route vulnerability reports to `security@caseyjhand.com`.
