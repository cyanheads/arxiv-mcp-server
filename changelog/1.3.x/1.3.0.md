# 1.3.0 — 2026-07-26

## Changed

- **`arxiv_get_metadata`**'s `not_found[].reason` output enum gains `version_not_in_mirror`, distinguishing a version-pinned ID the mirror lacks (live fallback disabled) from one genuinely absent from arXiv (`not_in_arxiv`). `PaperLookupResult.not_found` changes shape from `not_found_ids: string[]` to `not_found: { id, reason, detail? }[]`. A client branching exhaustively on `reason` must handle the new value. [#35](https://github.com/cyanheads/arxiv-mcp-server/issues/35)
- **`arxiv_get_metadata`** and **`arxiv://paper/{paperId}`** now throw `version_unavailable` (`ServiceUnavailable`) instead of `no_match` (`NotFound`) when every requested ID is a mirror version-miss — the ID is valid, only unreachable in this deployment, and the error detail names the version the mirror can serve. [#35](https://github.com/cyanheads/arxiv-mcp-server/issues/35)
- **`abstract_url`** on `PaperMetadata` is built from the versioned ID on every path, matching `pdf_url` — mirror-served and live-served records previously returned different URL shapes for the same paper. [#34](https://github.com/cyanheads/arxiv-mcp-server/issues/34)
- **`rate_limited` recovery hints** on `arxiv_search`, `arxiv_get_metadata`, `arxiv_read_paper`, and `arxiv://paper/{paperId}` now point at `error.data.cooldownAppliedMs`, the field the common 200 + "Rate exceeded." throttle path emits, instead of `error.data.retryAfter`, which only the less-common 429 path sets. [#9](https://github.com/cyanheads/arxiv-mcp-server/issues/9)
- **`arxiv://categories`** description now documents the flat `{ categories: [...] }` shape it returns, replacing prose describing a grouped shape it never emitted. [#29](https://github.com/cyanheads/arxiv-mcp-server/issues/29)

## Fixed

- **`ArxivService`** classifies HTTP status before content-type — a non-XML response at any status (a proxy 502, an edge 429 served as plain text) is now classified by its status instead of falling into the non-retryable serialization-error branch. An empty or whitespace-only body is now a transient `ServiceUnavailable` rather than reaching that branch. [#30](https://github.com/cyanheads/arxiv-mcp-server/issues/30)
- **`runRefreshSubprocess`** rejects on spawn failure, child `error`, non-zero exit, and a timeout kill instead of always resolving — the scheduler now records a killed or crashed mirror harvest as a failed job rather than a successful one. [#31](https://github.com/cyanheads/arxiv-mcp-server/issues/31)
