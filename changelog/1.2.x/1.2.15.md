# 1.2.15 — 2026-06-20

## Changed

- **`@cyanheads/mcp-ts-core` `^0.10.6` → `^0.10.9`** — notable framework changes adopted:
  - **`check-dependency-specifiers` devcheck step** (#246): new static guard hard-fails on floating specifiers (`latest`, `*`, pre-release dist-tags) in `package.json` dependency sections and `bun.lock`'s `workspaces` map — catches a `bun update --latest` writing a literal `latest` dist-tag into the lock. Synced as `scripts/check-dependency-specifiers.ts`.
  - **Plugin marketplace manifest checks in `lint:packaging`** (#240): check 10 validates `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json`/`mcp.json` — non-empty descriptions, unscoped machine name in display fields, full `package.json` name in the `npx -y` install arg. Gated by the new `devcheck.config.json` `packaging.pluginManifests` flag (enabled here).
  - **`ctx.content` collector** (#239): always-present `Context` collector for non-text content blocks (`.image()`/`.audio()`); collected bytes prepend to `content[]` and never enter `structuredContent`. No consumer impact — this server emits text only.
  - **Canvas SQL-gate classification** (#236): a `SELECT`/`WITH` statement that prepares but fails for a non-missing-table reason now throws `ValidationError` with `data.reason: 'invalid_sql'` and the DuckDB binder detail, instead of the misleading `non_select_statement`.
  - **`DuckdbProvider.describe({ tableName })`** (#235): filtered `describe()` no longer raises a DuckDB ambiguous-column Binder Error — the pushed `WHERE` predicates are now `t`-alias-qualified.
  - **Fresh-scaffold devcheck guards** (#242, #243, #237): changelog-sync, TODO/secret/antipattern, and skill-version checks skip cleanly outside a git repo or on a pruned `SKILL.md` instead of failing.
- **`devcheck.config.json`** — added `packaging.pluginManifests: true` to opt into the new plugin-manifest packaging checks.
- **Re-synced framework scripts** — `scripts/devcheck.ts`, `build-changelog.ts`, `check-framework-antipatterns.ts`, `check-skill-versions.ts`, `lint-packaging.ts` updated to the 0.10.9 toolchain; new `check-dependency-specifiers.ts` added.
- **Re-synced skills from framework** — `add-tool`, `api-auth`, `api-canvas`, `api-config`, `api-context`, `api-errors`, `api-services` (+ `graph`/`speech` references), `api-telemetry`, `field-test`, `git-wrapup`, `orchestrations`, `polish-docs-meta`, `report-issue-local`, `tool-defs-analysis`.
