# 1.2.10 — 2026-05-30

## Added

- **`enrichment` block on `arxiv_search`** — `effectiveQuery`, `totalFound`, `pageStart`, and optional `notice` now surface in `structuredContent` and the `content[]` markdown trailer via `ctx.enrich()`. Empty-result and pagination-overshoot guidance moved from `format()` into `ctx.enrich.notice()` so both channels carry the same recovery text.
- **`enrichment` block on `arxiv_list_categories`** — `totalCount` and optional `notice` surface through both channels. Missing-group guidance ("call without a group filter to see all valid groups") now reaches structured clients.

## Changed

- **`arxiv_search` `structuredContent`** — `total_results` renamed `totalFound`, `start` renamed `pageStart` (both now under `enrichment`; value and meaning preserved).
- **`@cyanheads/mcp-ts-core`** `^0.9.13` → `^0.9.16`
