# 1.2.14 — 2026-06-15

## Added

- **`arxiv_search` truncation disclosure** (`src/mcp-server/tools/definitions/arxiv-search.tool.ts`) — when `totalFound` exceeds the returned page, the handler calls `ctx.enrich.truncated()` and surfaces `truncated`/`shown`/`cap` enrichment fields plus a notice pointing at the next `start` offset. Satisfies the framework's new `capped-list-no-truncation` lint rule for `max_results`-capped output.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.9.21` → `^0.10.6`** — notable framework changes included:
  - **Server identity** (#213): `createApp()` now passes explicit `name: 'arxiv-mcp-server'` / `title: 'arxiv-mcp-server'` so `initialize` serverInfo and `/.well-known/mcp.json` report the unscoped repo name rather than the npm scope; enforced by the new `lint:packaging` check 9.
  - **DataCanvas SQL gate fails closed** (#210): non-SELECT and `pragma_*` table-function statements are rejected as `non_select_statement` `ValidationError` instead of leaking a generic `InternalError`.
  - **Env-boolean parsing** (#201): boolean env flags now parse via Zod `stringbool` and reject unrecognized values at startup instead of silently coercing to `false`.
  - **Sampling surface removed** (#220): `ctx.sample` and its types are gone (always `undefined` at runtime; deprecated by SEP-2577) — no consumer impact here, this server never used sampling.
- **MCPB bundle cleaner** — `bundle` script now runs `scripts/clean-mcpb.ts` after `mcpb pack` (#230); it prunes dev dependencies and strips `node_modules/**` agent-doc entries (`skills/`, `.claude/`, `.agents/`, `SKILL.md`) that root-anchored `.mcpbignore` patterns cannot reach.
- **`.mcpbignore`** — dev-dir patterns re-anchored to root (`/skills/`, `/.claude/`, `/.agents/`, etc.) so they can't strip nested `node_modules` runtime paths (#207).
- **Plugin display name** — `.codex-plugin/plugin.json` `interface.displayName` de-scoped to the bare `arxiv-mcp-server`.
- Re-synced skills from framework: `api-canvas`, `api-config`, `api-context`, `api-linter`, `api-mirror`, `api-testing`, `api-workers`, `add-prompt`, `add-resource`, `add-test`, `add-tool`, `code-simplifier`, `design-mcp-server`, `orchestrations`, `polish-docs-meta`, `release-and-publish`, `report-issue-framework`, `security-pass` updated; new `techniques` skill added.
- `scripts/check-framework-antipatterns.ts` and `scripts/lint-packaging.ts` synced to the framework toolchain (adds the `coerce-boolean-env-flag` antipattern rule and the post-bundle content + entrypoint-identity packaging checks).

## Fixed

- **Mirror config booleans were uncoercible from the environment** (`src/config/server-config.ts`) — `mirrorEnabled` and `mirrorFallbackLive` used `z.coerce.boolean()`, where `Boolean("false") === true` left them stuck on their non-default value. Switched to `z.stringbool()`, so `ARXIV_MIRROR_ENABLED` / `ARXIV_MIRROR_FALLBACK_LIVE` honor `true/false/1/0/yes/no/on/off` and reject anything else at startup.
