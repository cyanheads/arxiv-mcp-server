# 1.2.13 — 2026-06-02

## Changed

- **`@cyanheads/mcp-ts-core` `^0.9.16` → `^0.9.21`** — three notable framework fixes included:
  - HTTP transport per-request log context: per-request logs and traces now carry fresh request + trace/span IDs instead of the frozen boot context.
  - `fetchWithTimeout` strips query-string secrets (e.g. `?api_key=`) from error messages and logs.
  - `withRetry` fails fast on non-retryable errors; `ctx.fail` auto-populates the `retryable` flag.
- Re-synced skills from framework: `add-tool`, `add-service`, `api-canvas`, `api-context`, `api-linter`, `api-utils`, `design-mcp-server`, `release-and-publish` updated; new `api-mirror` and `orchestrations` skills added.
- Added `release:github` script (`scripts/release-github.ts`) to `package.json`.
- Added `scripts/check-skill-versions.ts` and `scripts/devcheck.ts` (standalone devcheck runner).
- Plugin manifests (`.claude-plugin/plugin.json`, `.codex-plugin/mcp.json`) normalized — client-config key renamed to full package name `@cyanheads/arxiv-mcp-server`.

## Dependencies

- `@cyanheads/mcp-ts-core` `^0.9.16` → `^0.9.21`
- `vitest` `^4.1.7` → `^4.1.8`
