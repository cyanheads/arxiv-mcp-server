# 1.2.1 — 2026-05-21

## Fixed

- **Dockerfile build stage** — `bun install --frozen-lockfile` now runs with `--ignore-scripts`, matching the production stage. The Bun base image (`oven/bun:1.3`) ships without a C++ toolchain, so `better-sqlite3`'s `node-gyp` install script (added in v1.2.0 as the Node-runtime mirror fallback) hard-failed the `docker build`. The runtime image is Bun-only — `src/services/arxiv/mirror/store.ts` selects `bun:sqlite` via `runtimeCaps.isBun` and never imports `better-sqlite3` — so the unbuilt native module is inert weight either way.
