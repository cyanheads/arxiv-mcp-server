# 1.2.8 — 2026-05-28

## Added

- **`landing.requireAuth: false`** passed explicitly in `createApp()` — the landing page now serves the full tool/resource/prompt inventory without authentication (public-catalog behavior), restoring the pre-0.9.13 default for `MCP_AUTH_MODE=none` deployments.
- **npm keywords** — `bun`, `stdio`, `streamable-http` added to `package.json` for better discovery; surfaced on `GET /mcp` via the new framework `server.keywords` field.

## Changed

- **`@cyanheads/mcp-ts-core`** ^0.9.6 → ^0.9.13.
  - **`MCP_HTTP_MAX_BODY_BYTES`** — oversized HTTP requests now rejected with `413` before the SDK parses the body (default 1 MiB).
  - **HTTP session-init gate** — stateful HTTP mode now rejects non-`initialize` requests missing `Mcp-Session-Id` with `400`.
  - **`httpErrorHandler`** — `401`, `403`, `400`, `404` responses now log at `warning` instead of running the full error-handler pipeline with stack traces.
  - **`GET /mcp` keywords** — `package.json` keywords surfaced in the HTTP status response alongside name, version, and description.
- **`@biomejs/biome`** ^2.4.15 → ^2.4.16.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.9.6 → ^0.9.13
- `@biomejs/biome` ^2.4.15 → ^2.4.16
