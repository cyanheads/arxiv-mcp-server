# 1.2.2 — 2026-05-21

## Fixed

- **Dockerfile production stage** copies the mirror lifecycle scripts (`scripts/arxiv-mirror-{init,refresh,verify}.ts` and shared `scripts/_mirror-context.ts`) from the build stage into the final image. v1.2.0 added the scripts but the production stage only carried `dist/` — `bun run mirror:init` inside the container hit `Module not found "scripts/arxiv-mirror-init.ts"` and the operator couldn't cold-init the mirror at all.
- **`package.json` `files`** array now includes the same four mirror scripts so npm-installed copies of the package (e.g. via `bun add @cyanheads/arxiv-mcp-server`) ship them too. Previously a Bun-runtime installer hit the same `Module not found` when trying `bun run mirror:init`.

No source changes. `dist/` output and runtime behavior are identical to v1.2.1 — the mirror module is unchanged; only packaging is fixed.
