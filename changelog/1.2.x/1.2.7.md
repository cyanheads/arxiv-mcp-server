# 1.2.7 — 2026-05-26

## Fixed

- **`ArxivService.search()` recency bypass** — live API failures during the recency-bypass path now fall back to `searchMirror` instead of propagating the error. Previously a transient live API failure would surface to the caller even when a ready mirror existed ([#16](https://github.com/cyanheads/arxiv-mcp-server/issues/16)).
- **`ArxivService.readContent()` metadata fetch** — `fetchLivePapers` is now wrapped in try/catch; on failure the service falls back to `getPapersByIds` + `rowToMetadata` from the mirror. Latest-version metadata is returned instead of a hard error ([#16](https://github.com/cyanheads/arxiv-mcp-server/issues/16)).
