# 1.7.1 — 2026-10-23

## Changed

- **`arxiv_read_paper` unparseable PDF** — a PDF the parser rejects fails `pdf_extraction_failed` (`NotFound`, with `paperId` and `pdfUrl`) instead of an `InternalError` with reason `pdf_text_extract_failed`, and a held ar5iv failure is reported ahead of it. The error's `when` and `recovery` cover both causes (#81).
- **Mirror schema v4** — `paper_categories.published` and date-ordered indexes. On first start against a v3 mirror the file migrates in place (several minutes on a full-size mirror) and searches are served live until it finishes; `mirror:verify` checks the v4 objects (#78).
- **`arxiv_search_papers` `totalFound`** — a mirror search with no free-text term counts exactly only for one category code. Every other term-less search (`cat:cs`, two categories, a date window alone) stops at 50,000 and sets `totalFoundIsLowerBound: true`; pages come from the index (#78).

## Fixed

- **`arxiv_search_papers` mirror query translation** — the mirror reads a query as arXiv does: adjacent terms join with `OR`, `AND` / `OR` / `ANDNOT` share one precedence grouped to the right, and only uppercase operators are operators. The `query` description says so (#82).
- **Queries the mirror answered with a different set than arXiv** now go live: `quantum cat:cs.LG`, a field prefix with no value (`ti: x`, `ti:`), an empty phrase, `rn:` and `id:` operands, a `cat:` wildcard matching no category, and a word arXiv's index drops beside `OR` (`ti:quantum and ti:graph`). A `start` of 10,000 or more on them is refused `start_beyond_result_limit` (#82).
- **A free-text term beside a multi-code category group** (`quokka AND cat:cs`) tests each match against its own category list and no longer reads the whole group (#84).
