# 1.7.2 — 2026-10-25

## Added

- **Real-document read-path tests** — `arxiv_read_paper`'s rung selection, cleaning, paging, outline cap, and PDF rung run against five CC BY arXiv documents under `tests/corpus/`, each stored with a license record the test run checks; they replace the 21 captured pages in `tests/fixtures/arxiv-html/` (#80).

## Changed

- **Mirror schema v5** — the first writer open migrates a v4 mirror in place (about 4.5–7.5 min on a full-size mirror) and searches are served live until it finishes. It repairs about 1.19M stored papers and defines `paper_categories_paper_id_idx` as `(paper_id, category)`; `mirror:verify` checks it. Rolling back to 1.7.1 or earlier and refreshing stores the references again, so after rolling forward run `UPDATE schema_version SET version = 4` and `mirror:verify` (README) (#88, #85).

## Fixed

- **`content[]` of `arxiv_search_papers`, `arxiv_get_metadata`, and `arxiv_read_paper`** reads back through a CommonMark parse exactly as `structuredContent` carries it. Inline fields are escaped, the abstract is a `> ` quote, abstract and PDF URLs are `[url](<url>)` links, and the `arxiv_read_paper` body sits in a code fence (`start`, `body_characters`, and outline offsets still index the body). The outline nests under the open headings, and the server `instructions` call paper text author-written data (#87).
- **Mirror apostrophes and quotes** — numeric character references decode in the OAI harvester and the live Atom parser, so mirror and live text match; `ti:"don't"` on the mirror finds 1,016 papers instead of 0 (#88).
- **Mirror searches over two or more category groups with no free-text term** probe one covering seek per candidate, driven by the group with the fewest rows; a group with no row answers 0. `cat:cs AND cat:stat` drops from 5.2–6.2 s to 0.25–0.46 s a page, `cat:cs AND cat:math` from about 12.6 s to 0.73–0.99 s (#85).
