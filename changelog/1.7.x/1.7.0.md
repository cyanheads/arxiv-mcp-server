# 1.7.0 — 2026-10-21

## Changed

- **Breaking — `arxiv_read_paper` PDF extraction is bound by `ARXIV_READ_TIMEOUT_MS`:** a read whose extraction ends past the deadline now fails `Timeout` instead of returning the text late; raise the variable for clients that wait longer (#73).
- **PDF text extraction runs in a worker thread**, at most two at once, so `/healthz` and other calls answer during a long extraction; a read waiting for a slot counts the wait against its deadline. A worker that dies before replying fails the read `ServiceUnavailable` (#73).

## Fixed

- **`arxiv_read_paper` with the arXiv API hanging** — an unversioned read of a paper the mirror holds waits on its live lookup at most `ARXIV_API_TIMEOUT_MS`, queue wait included, then answers from the mirror; reads queued behind the hang no longer time out (#79).
- **`arxiv_read_paper` `revision_unconfirmed`** — an ar5iv body read with mirror metadata carries `true` even when the stored version is v1, since a mirror row can trail arXiv's latest version (#79).
- **`arxiv_search_papers` mirror query translation** — `cat:` and `submittedDate:` operands keep arXiv's meaning, with `AND` binding tighter than `ANDNOT` and `OR`. A query where such an operand is not a conjunct of the whole query, or that has no positive term, goes live (#65).
- **A SQLite error at query time** (a corrupt mirror page) is a failed mirror open: search, `arxiv_get_metadata`, `arxiv://paper/{paperId}`, the newest-first bypass, and `arxiv_read_paper` log a warning and go live or keep the live failure, not `ValidationError` carrying SQLite's text (#76).
- **Harvest resume** — `mirror:init` and `mirror:refresh` restart at `from=last_datestamp` instead of a saved resumption token, which survives only inside the datestamp a run could not clear; a record arXiv modified mid-harvest is no longer skipped (#62).
- **Mirror scripts from an npm install** — `scripts/tsconfig.json` ships and maps `@/*` to `src/`, then `dist/`, so `mirror:*` no longer fail with `Cannot find module '@/config/server-config.js'`; the Docker image stops writing its own `tsconfig.json` (#75).
- **The `.mcpb` bundle** leaves out `tests/`.
