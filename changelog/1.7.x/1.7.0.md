# 1.7.0 — 2026-10-21

## Changed

- **Breaking — `arxiv_read_paper` PDF extraction is bound by `ARXIV_READ_TIMEOUT_MS`:** a read whose text extraction ends past the deadline now fails `Timeout` instead of returning `pdf_text` late, and a read waiting for one of the two extraction slots counts that wait against the same deadline; raise the variable for clients that wait longer (#73).
- **PDF text extraction runs in a worker thread**, at most two at once, so `/healthz` and other calls answer during a long extraction. A worker that dies before replying fails the read `ServiceUnavailable` (#73).

## Fixed

- **`arxiv_read_paper` with the arXiv API hanging** — an unversioned read of a paper the mirror holds waits on its live lookup at most `ARXIV_API_TIMEOUT_MS`, queue wait included, then answers from the mirror; reads queued behind the hang no longer time out (#79).
- **`arxiv_read_paper` `revision_unconfirmed`** — an ar5iv body read with mirror metadata carries `true` even when the stored version is v1, since a mirror row can trail arXiv's latest version (#79).
- **`arxiv_search_papers` mirror query translation** — the mirror reads a query with arXiv's precedence, `AND` binding tighter than `ANDNOT` and `OR`, so `a ANDNOT b AND c` excludes only papers matching both `b` and `c`, and `cat:` and `submittedDate:` operands keep arXiv's meaning. A query where such an operand is not a conjunct of the whole query, that leaves only `ANDNOT` terms once those operands are taken out, or whose parentheses do not balance goes live (#65).
- **A SQLite error at query time** (a corrupt mirror page) is a failed mirror open: search, `arxiv_get_metadata`, `arxiv://paper/{paperId}`, the newest-first bypass, and `arxiv_read_paper` log a warning and go live or keep the live failure, not `ValidationError` carrying SQLite's text (#76).
- **Harvest resume** — `mirror:init`, `mirror:refresh`, and the in-process refresh keep a resumption token only when a run stops inside the datestamp it started on, at its deadline or after resuming a saved token there. Any other stop — after the checkpoint moved, on a failed page, or on a cancellation (Ctrl+C during `mirror:init`'s outage wait included) — keeps none, so the next run restarts at `from=last_datestamp` and does not skip a record arXiv modified in between. Inside a datestamp a kept token covers, a record arXiv re-modifies can still be skipped (#62).
- **Mirror scripts from an npm install** — `scripts/tsconfig.json` ships and maps `@/*` to `src/`, then `dist/`, so `mirror:*` no longer fail with `Cannot find module '@/config/server-config.js'`; the Docker image stops writing its own `tsconfig.json` (#75).
- **The `.mcpb` bundle** leaves out `tests/`.
