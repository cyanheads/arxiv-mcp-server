# 0.1.19 — 2026-05-18

## Fixed

- **`arxiv_get_metadata` preserves caller-supplied input order** ([#5](https://github.com/cyanheads/arxiv-mcp-server/issues/5)) — arXiv's API returns batch lookups in its own internal order (typically submitted-date descending), so a caller stitching results back to an ordered reference list silently misaligned. `getPapers` now re-indexes by a `Map<baseId, paper>` and emits entries in input order; `stripVersion` is applied on both sides so versioned and unversioned inputs line up against arXiv's always-versioned response.
- **`arxiv_read_paper` honors version suffix in HTML URLs** ([#10](https://github.com/cyanheads/arxiv-mcp-server/issues/10)) — `fetchHtml` was stripping the version before composing the upstream URL, silently serving the latest render even when the caller asked for `2401.12345v1`. Both `arxiv.org/html` and `ar5iv` accept versioned paths verbatim; pass `paperId` through and the PDF fallback hint now also points at the requested version.
- **Category typo suggestions rank by edit distance** ([#6](https://github.com/cyanheads/arxiv-mcp-server/issues/6)) — `suggestCategories('cs.LB')` returned the first five `cs.*` codes alphabetically (`cs.AI, cs.AR, cs.CC, cs.CE, cs.CG`) regardless of similarity to the typo. `suggestCategories` now runs the same Levenshtein ranking inside the prefix-match branch as it does on the fallback path, so `cs.LB` surfaces `cs.DB, cs.LG, cs.LO` ahead of alphabetically-earlier codes.
- **`arxiv_search` query field-prefix docs** ([#7](https://github.com/cyanheads/arxiv-mcp-server/issues/7)) — `au:` is token-based and matches common surnames overly broadly; description now calls this out and recommends quoting multi-token names (`au:"hinton g"`) or pairing with a topical clause to disambiguate. `cat:` is exact, not fuzzy — also noted.

## Added

- **MathML → LaTeX collapse in `arxiv_read_paper`** ([#4](https://github.com/cyanheads/arxiv-mcp-server/issues/4)) — a single inline `70%` on an arXiv HTML page expands to ~250 chars of presentation MathML; the same content is present in the `<annotation encoding="application/x-tex">` child as ~4 chars. `collapseMathML` runs before LaTeXML class/id stripping, preserves inline-vs-block distinction (`$…$` vs `$$…$$`), falls back to the `alttext=""` attribute when no annotation child is present, and decodes HTML entities (`&lt;`, `&gt;`, `&amp;`) in the LaTeX source. Math-dominant test fixtures shrink 20×+; real papers (mixed prose + math + bibliography) typically see 2-3× shrink — every saved byte goes to the `max_characters` budget for actual paper content.
- **Adaptive rate-limit cooldown** ([#9](https://github.com/cyanheads/arxiv-mcp-server/issues/9)) — pre-fix, every rate-limit event applied the same 5s cooldown. A persistently throttled session thrashed at the floor instead of backing off. `ArxivService` now tracks `consecutiveRateLimits` and grows the cooldown geometrically (5s → 10s → 20s → 30s capped); the counter resets to 0 on the next successful API response. Both the 200 OK + `Rate exceeded.` body path and the HTTP 429 path now emit symmetric `error.data`: `{ url, status, body, cooldownAppliedMs, consecutiveRateLimits, reason, recovery }` (429 adds `retryAfter`), so callers can branch on a single shape. When a `Retry-After` header is larger than the adaptive value, the header wins.
