# 0.1.18 — 2026-05-16

## Added

- **Server-level `instructions`** on `createApp()` ([cyanheads/mcp-ts-core#91](https://github.com/cyanheads/mcp-ts-core/issues/91)) — one-paragraph orientation describing the `arxiv_*` tool surface, paper ID formats, and search query syntax. Surfaces on every `initialize` response so spec-compliant clients can forward it to the model as session-level system context, instead of leaking the same guidance into every tool description.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.8.19 → ^0.9.1`** — minor framework bump. Highlights affecting this server: the new `instructions` field (adopted above), cross-vendor JSON Schema portability lint family (`schema-format-portability` and four siblings — current arXiv schemas pass), Workers `nodejs_compat` boot fix + SSRF DNS validation extended to the Worker runtime, definition linting moved from startup to build-time only (faster cold starts; lint is still gated in `devcheck` / `lint:mcp`), changelog summary cap raised 250 → 350 chars.
