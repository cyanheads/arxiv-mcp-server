# 1.6.1 — 2026-10-18

Stop any server build older than 1.6.1 that shares the mirror file before upgrading: an older build migrates the file on open and ignores the migration lease.

## Changed

- **`arxiv_read_paper` runs on one deadline, `ARXIV_READ_TIMEOUT_MS`** (default 50000) covering the metadata lookup, every content request, the replay, and the waits between them. A read still running when it passes fails `Timeout`; raise the variable for a client that waits longer than 60 s (#69).
- **`ARXIV_API_TIMEOUT_MS` and `ARXIV_CONTENT_TIMEOUT_MS`** accept whole milliseconds from 1 to 2147483647; any other value is a configuration error at startup, as for `ARXIV_READ_TIMEOUT_MS` (#74).
- **A lookup holding a superseded old-style pin that arXiv answers HTTP 500 for** now sends one unversioned request in place of the identical retry. A pin it cannot serve reports `version_not_served` (names the latest version and the pinned version's PDF) on `arxiv_get_metadata`, `arxiv_read_paper`, and `arxiv://paper/{paperId}`; the same call made again resolves a transient 500 (#53).
- **A response body that stalls after its headers** fails `Timeout` and is not replayed, like a host that hangs before them; on ar5iv the failure is held until the PDF rung also fails (#70).
- **The server opens the mirror query-only** and no longer creates, seeds, or migrates the file. A file on an older schema (built before 1.5.0, schema v1 or v2) is read live until a writer run migrates it: `mirror:refresh`, `mirror:verify`, or the HTTP cron's child, which now starts at once when it finds an older schema (#55, #71).
- **One writer migrates the mirror file at a time.** A second writer changes nothing and fails `migration_in_progress`: the mirror scripts exit 75 naming the holder, the cron's child reports `skipped`, and a reader reports the file as migrating (#71).
- **Mirror searches run in a worker thread**, so none blocks the request thread; a cancelled call settles at once (#58).
- **`mirror:init` waits out arXiv outages** and re-sends the page; Ctrl+C or SIGTERM ends the wait and the next run resumes (#61).

## Fixed

- **`arxiv_get_metadata` partial results** — when the mirror serves some IDs and the live lookup for the rest fails, the served papers come back and each unanswered ID reports `live_lookup_failed`; the call still fails when the mirror served none or arXiv rejected the lookup (#67).
- **`arxiv_read_paper` on a paper the mirror lacks** — an arXiv outage throws the live error instead of `no_match` (#68).
- **`arxiv_search_papers` newest-first on a mirror that matches nothing** — when the live API fails on the recency bypass (`sort_by=submitted` descending), the live error comes back instead of an empty result (#68).
- **`arxiv_read_paper` `revision_unconfirmed`** — set `true` on an ar5iv body, which may be another revision than `paper_id`; absent on other sources and on an unversioned read of a paper whose only version is v1 (#63).
- **HTML renders built from an included PDF** — a page with no structural heading that holds only an `\includepdf` placeholder or no text falls through to the next rung (#57).
- **`arxiv_read_paper` `outline`** keeps headings that carry a `style` attribute (#66).
- **Mirror DDL** runs one statement at a time, so a failed step surfaces on Bun (#64).
- **Resumption-token recovery** falls back to the checkpoint once per checkpoint; a second rejection before it advances fails `token_recovery_stalled` (#59).
- **A 4xx whose body stalls or drops** in the OAI harvest fails `Timeout` or `ServiceUnavailable` naming the host and status, not as a raw `TimeoutError`, and is not replayed (#72).

## Dependencies

- `unpdf` `^1.8.1` → `^1.9.0`
- `vitest` `^5.0.4` → `^5.0.5`
